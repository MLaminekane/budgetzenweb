# Changelog

Toutes les modifications notables apportées à ce projet seront documentées dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-30

### Ajouté
- Interface de tableau de bord avec visualisation des soldes, revenus et dépenses
- Système de gestion des transactions avec catégorisation
- Support multi-devises (FCFA, EUR, USD, CAD)
- Système de thèmes (clair, sombre, système)
- Assistant financier avec chat IA
- Gestion des profils utilisateurs
- Système de notifications pour les dépenses, abonnements et budgets
- Gestion des catégories personnalisées
- Calendrier des transactions
- Statistiques et graphiques

### Fonctionnalités techniques
- Authentification sécurisée avec Supabase
- Interface utilisateur responsive avec Tailwind CSS
- Composants UI modernes avec shadcn/ui
- Gestion d'état avec React Query
- Support des thèmes avec next-themes
- Formatage des devises localisé
